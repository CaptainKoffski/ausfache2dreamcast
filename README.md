# Akatsuki Blitzkampf Ausf. Achse — Naomi → Dreamcast

A static binary conversion of **Akatsuki Blitzkampf Ausf. Achse** (Subtle
Style, 2008, Sega Naomi M4 cartridge, 841-0058C) to the **Sega Dreamcast** —
no game source code, done with AI heavy-lifting (Claude Code) driving the
reverse engineering and conversion, with a human running the real-hardware
test loop.

**Status: not started.** The project brief is `REQUIREMENTS.md`.

Ausf. Achse has never been ported to any platform. The game was picked via
the [naomi2dreamcast](https://github.com/CaptainKoffski/naomi2dreamcast)
umbrella project — the portability assessment of the whole Naomi library
([assessment](https://github.com/CaptainKoffski/naomi2dreamcast/blob/main/assessments/ausfache.md),
84.4 S). Method lineage: the
[Cleopatra Fortune Plus](https://github.com/CaptainKoffski/cfp2dreamcast) and
[Senko no Ronde Special](https://github.com/CaptainKoffski/senkosp2dreamcast)
ports.

This repository will contain **only original work** — loader, shims, patch
generators, scripts, and the knowledge base. It contains **no copyrighted
game data**; you supply your own legally-obtained romset and BIOS.
